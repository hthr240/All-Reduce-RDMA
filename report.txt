Status:

Implementation notes:
- The goal is to build a ring-based process-group library using RDMA verbs.
- Each rank communicates with a previous and next neighbor in a logical ring.
- The public API is intentionally minimal and stable:
  - connect_process_group(char *servername, void **pg_handle)
  - pg_all_reduce(void *sendbuf, void *recvbuf, int count, DATATYPE datatype, OPERATION op, void *pg_handle)
  - pg_close(void *pg_handle)
- The library must support all-reduce semantics across ranks using a ring algorithm.
- The initial implementation passes compilation and validates the project structure before adding the actual RDMA collective logic.

Design intent:
- `pg_handle_t` is the process-group handle and will hold all local and remote metadata needed for ring communication.
- `DATATYPE` and `OPERATION` are public enums that define supported element types and reduction operations.
- `main` is responsible for mapping command-line rank and host-list input into a rank-local process-group context.
- The actual distributed communication logic will be implemented in later phases after the bootstrap and topology are complete.

Phase 0 requirements lock
-------------------------

Public API
- connect_process_group(char *servername, void **pg_handle) creates the local
  process-group handle. The handle is opaque to the caller.
- pg_all_reduce(sendbuf, recvbuf, count, datatype, op, pg_handle) performs an
  element-wise all-reduce and writes the complete result to recvbuf on every
  rank. The call returns 0 on success and -1 on failure.
- pg_close(pg_handle) releases all resources owned by the handle. It is safe to
  call it with NULL.

Supported values
- DATATYPE values are PG_INT32, PG_INT64, PG_FLOAT, and PG_DOUBLE.
- OPERATION values are PG_SUM, PG_MAX, and PG_MIN.
- Unsupported datatype or operation values are rejected with a nonzero result.

Process-group and command line
- Ranks are zero-based: rank 0 is the first host in the -list argument.
- The distributed form is:
  ./ring_allreduce -myindex <rank> -list <host1> [host2 ...]
- The standalone form accepts one hostname and is used for local bootstrap
  development.
- The rank must be within the supplied host list. The host list order is the
  logical ring order and must be identical at every rank.

Buffer and count semantics
- sendbuf points to count input elements and recvbuf points to count output
  elements. The caller owns both buffers and keeps them valid for the duration
  of pg_all_reduce.
- sendbuf and recvbuf may refer to the same storage; the implementation must
  preserve the input values while building the result.
- count must be nonnegative. count == 0 is a successful no-op when the handle
  and buffer arguments are otherwise valid.
- Counts do not need to divide evenly by the number of ranks. The collective
  must preserve element order and handle the remainder explicitly.
- The implementation must not retain caller buffer addresses after
  pg_all_reduce returns.

Output and diagnostics
- stdout is reserved for benchmark or machine-readable result data.
- Diagnostics, validation failures, and progress messages go to stderr.
- The final implementation must not print debugging text to stdout.

Phase 1 status: local Verbs foundation
--------------------------------------

The Phase 1 implementation keeps the public API and Makefile build contract
unchanged while adding the first local RDMA resources. On initialization it:
- discovers the first available Verbs device and opens its context;
- selects an active device port;
- allocates a protection domain;
- allocates and registers a communication buffer with local and remote access;
- creates a completion queue; and
- creates an RC queue pair and moves it to INIT.

Remote metadata exchange and the RTR/RTS transitions are intentionally deferred
to the following phases. Cleanup handles partial initialization and releases
resources in reverse dependency order. A machine without an available Verbs
device is expected to fail initialization cleanly; compilation remains
possible wherever the libibverbs headers and library are installed.
